3. Una release/evento GitHub ogni settimana
   Questo secondo me è il cuore della strategia.
   Non fare commit casuali.
   Creerei un heartbeat settimanale.
   Ogni settimana deve accadere almeno una cosa pubblicamente raccontabile:
   Openapi MCP v0.x
   New Python SDK feature
   New CLI command
   New Agent Skill
   New example
   New integration
   New tutorial
   New benchmark
   New template
   Questo crea una cosa importantissima:
   newsworthiness.
   Non devi ogni settimana inventare un progetto.
   Devi avere ogni settimana qualcosa da raccontare.
